How versions work
A five-minute tour. No jargon, nothing to memorise.
The one-sentence version
You work in a folder on your own computer. Every so often you save a version — a copy of the whole folder exactly as it is right now, that you can always come back to. When you're happy, you send your versions to the team's copy so your teammates can pick them up. They're doing exactly the same thing, from their own computers.
